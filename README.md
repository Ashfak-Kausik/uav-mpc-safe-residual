# UAV MPC Safe Residual

This project contains the code, notes, and experiment assets for studying a UAV model predictive control (MPC) setup with a safe residual formulation.

## Repository structure

- `src/` — source code for the project
- `tests/` — test suite and validation scripts
- `configs/` — configuration files for experiments and model parameters
- `experiments/` — experiment definitions and outputs
- `notebook/` — derivations and notes on dynamics, frames, forces, and control-related topics

## Purpose

The goal of this repository is to explore and test a UAV control formulation that combines MPC with residual-based safety logic, emphasizing model fidelity, analysis, and iterative experimentation.

## Getting started

1. Review the notes in `notebook/` for the underlying derivations and project background.
2. Inspect the configuration files in `configs/` and experiment definitions in `experiments/`.
3. Run the project code from `src/` and validate with tests under `tests/`.

## Notes

This repository is intended for research and experimentation. Update the project-specific details as the implementation evolves.
